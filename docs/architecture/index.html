Where the decisions are made

A point-in-time backtest of a William O'Neil momentum strategy. Jev — TypeSafe's System One model — picks the entries and decides the exits. Deterministic code owns the data, the signals, the stops and the fills, and never delegates risk. A paired deletion experiment, not a single run, decides whether any of it beat the mechanical rules.
